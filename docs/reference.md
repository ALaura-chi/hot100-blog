参考页面：<https://slantedbookshelf.github.io/Blog/posts/hot_100/>。

输入依据：用户提供的浅深主题桌面截图、之前 A03 留存的 390×844 手机截图，以及 `reference/original-plan.md` 的分类和 100 题附录。该原规划保留历史状态，仅作为输入备份；新项目的实施状态见 `implementation.md`。

保留的视觉和阅读方式：绿色主题、浅网格背景、桌面左侧独立滚动索引、右侧长文、难度点和文字徽标、深底代码块、当前题目反馈、页脚与主题切换。

有意采用的差异：

- 网站名和 GitHub 链接使用 ALaura；日期为新项目创建日期。
- 首页、分类、关于和 404 均为本项目实际页面；文章底部不链接不存在的 SQL 文章。
- 手机目录可折叠，长代码局部横向滚动；参考手机截图的目录布局不直接沿用。
- 代码为 Java 五个样例，附独立本地测试；其余 95 题保留官方链接并明确待补充。
- 代码主题选用 Astro 内置 `github-dark`；字体使用系统字体，不依赖远程字体服务。
- 网格和波纹重新实现，支持减少动效；不承诺与原站每一帧或每一个像素一致。
- 不显示无后端的 AI 问答入口。
