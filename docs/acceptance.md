## 内容与外链的实际边界

100 道题的题号、题名、分类、难度和 URL 均与规划附录的数据逐项一致，官方域名、格式和去重通过自动检查。进一步对全部 100 个官方 URL 发起只读网页核对，部分使用同一题目的官方 description 子路由重试：96 个返回的题号和题名匹配；238 的官方题名为“除了自身以外数组的乘积”，规划采用“除自身以外数组的乘积”，两者题号和 URL 相同。234、33、300 的直接读取仍超时，未判为链接失效。逐项记录在 `checks/external-links.json`；这仍不等于全部外链均已实时访问成功。

五篇完整样例为 1、283、42、200、287，覆盖简单、中等、困难；有思路、代码、复杂度、易错点和本地测试。未登录力扣代用户提交，未编造平台通过记录。95 篇待补充是第一版约定的内容范围。
